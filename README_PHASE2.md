# PT Clinical Operating System - Phase 2 Clinical Engine Foundation

This package keeps Phase 1C full restore and adds an expandable clinical engine layer:

- Clinical Intake Engine
- Orthopedic Testing Engine
- Neuro Engine
- Neurodynamic Differentiation
- Movement Impairment Engine
- Differential Engine
- Red Flag Engine
- Treatment Direction Engine
- Progression Engine
- Outcome Measures
- Return-to-Function Pathways
- HEP Intelligence Categories

This is built so more content can be added by editing only:

- data/clinicalEngineKnowledge.ts
- data/hepDatabase.ts
- data/interventionLibrary.ts
- data/clinicalDetails.ts
- data/clinicalSupport.ts

Apply:
1. Unzip
2. Copy app, components, data, lib, types, utils into C:\Users\USER\pt-clinical-system
3. Replace files
4. npm run build
5. git add .
6. git commit -m "Phase 2 clinical engine foundation"
7. git push
